# What is Atlas?

Atlas is a self-healing deployment pipeline that takes your application from source code to a live URL automatically. It analyzes your project, determines the framework, executes the build, and if the build fails, uses an LLM to patch the code and retry. 

Once the build is successful, Atlas deploys your application to cloud providers like Vercel, Render, or Netlify, and runs a health check to ensure everything is working correctly.
